# TillBook downloads

Quotes, sales orders, invoices, credit notes, purchase orders, payments and stock for small shops. Windows desktop app; your data stays on your own PC.

**Download:** open the [latest release](https://github.com/JannieDuiwel/TillBook-releases/releases/latest) and run `TillBook-<version>-setup.exe`.

Windows may warn that the installer is from an unknown publisher (it is not code-signed yet): click **More info**, then **Run anyway**.

Installed copies update themselves from this page when they start.
